Proyecto: Plataforma de Monitoreo Ecológico y Huella de Carbono

Propósito: Una suite web interactiva orientada a la concienciación climática corporativa y el cálculo de impacto ambiental en tiempo real.

1. Explicación del Proyecto

Este sistema busca transformar datos complejos de emisiones de gases de efecto invernadero en gráficos comprensibles para el usuario común. La plataforma permitirá a empresas y ciudadanos registrar sus consumos diarios, recibir recomendaciones automatizadas para mitigar su huella ecológica y participar en un mercado comunitario de créditos de carbono locales.

2. Tecnologías y Recursos Utilizados

Tecnología / Recurso Descripción y Justificación
HTML5 Semántico Garantiza una estructura accesible (SEO) mediante etiquetas como section, article, nav y figuras para lectores de pantalla.
Chart.js (CDN) Biblioteca externa liviana que se utilizará para renderizar los gráficos de barras, líneas y sectores sin recargar la página.
Fetch API Para conectar la interfaz de usuario con servicios públicos de datos climáticos mundiales de forma asíncrona.

3. Componentes Interactivos con JavaScript

Componente Mecánica de Funcionamiento con JS
Calculadora Dinámica Captura eventos 'input' en tiempo real sobre consumo eléctrico y transporte, aplicando factores de conversión sin procesar en servidor.
Panel de Gráficos Interactivos Actualización y re-renderizado dinámico de variables ambientales al alternar filtros temporales (diario, mensual, anual).
Filtro Avanzado de Proyectos Buscador de iniciativas de reforestación basado en matrices que ocultan o muestran nodos del DOM instantáneamente según la región geográfica.
Notificaciones Tipo Toast Alertas temporales autodestruibles mediante setTimeout para confirmar el guardado exitoso de registros diarios en la sesión.
